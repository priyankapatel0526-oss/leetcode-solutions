# Reverse a String

## Problem: Reverse a String (Easy)

**Link:** https://leetcode.com/problems/reverse-string/

### Approach

I used two pointers, one at the beginning and one at the end of the string.
I swapped the characters and moved both pointers toward the middle.

### Complexity

- Time: O(n)
- Space: O(1)

### Notes

I tested the program with two test cases in VS Code.
The solution reverses the string in-place without using extra memory.
The solution was also accepted on LeetCode.
